
# Calculadora Extendida - Java Swing

## Descripción

Este proyecto consiste en una calculadora extendida desarrollada en Java utilizando Java Swing. Permite realizar operaciones matemáticas básicas, conversiones de temperatura y operaciones adicionales desde una misma interfaz gráfica.

## Funciones

### 1. Operaciones aritméticas
- Suma.
- Resta.
- Multiplicación.
- División.
- Validación para evitar la división entre cero mediante `if`.

### 2. Conversor de temperatura
- Fahrenheit a Celsius.
- Celsius a Fahrenheit.

### 3. Operaciones adicionales
- Cálculo de raíz cuadrada.
- Cálculo de potencias mediante exponentes.

## Tecnologías utilizadas

- Java.
- Java Swing.
- Programación Orientada a Objetos .
- Apache NetBeans IDE.

## Estructura del proyecto

```text
src/
├── Calculadora.java
├── ConversorTemperatura.java
├── Raizcuadrada_Exponente.java
└── CalculadoraGUI.java
```

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir Apache NetBeans.
3. Seleccionar **File → Open Project**.
4. Buscar la carpeta del proyecto.
5. Ejecutar el proyecto desde NetBeans.
